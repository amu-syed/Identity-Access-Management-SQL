# Identity-Access-Management-SQL
## Overview
This repository contains a cybersecurity-focused SQL database schema designed to manage user identities, departmental permissions, and system access levels. It includes sample data and analytical queries used to audit security privileges and detect potential anomalies.

## Features
# RBAC Architecture: 
Structured tables mapping users to specific roles and clearance levels.

# Security Auditing Relational:
joins to verify active users and their corresponding permissions to ensure the principle of least privilege.

* **Threat Detection:** Aggregate queries designed to parse simulated security logs and identify brute-force login attempts based on IP frequency.

## Technologies Used
* SQL (Data Definition Language & Data Manipulation Language)
* Tested via SQLite / DBeaver
